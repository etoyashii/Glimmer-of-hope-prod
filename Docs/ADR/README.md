# Architecture Decision Records

Un ADR enregistre une decision structurante : son contexte, ce qui a ete decide, ce
que ca coute, et ce qui a ete ecarte. On ne le reecrit pas apres coup — on en ajoute
un nouveau qui remplace le precedent.

**Une regle qui n'est pas dans ce dossier n'est pas opposable.** Les ADR vivaient
jusqu'ici dans un espace personnel que personne d'autre ne pouvait lire : une regle
que l'equipe ne peut pas consulter n'est pas une regle, c'est un avis.
