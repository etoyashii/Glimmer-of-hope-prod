# Prefab Painter Tool (Free Version)

## Overview

Prefab Painter Tool is a Unity tool for painting prefabs into your scene efficiently and naturally. This free version allows you to assign up to 3 prefabs simultaneously and offers basic painting and erasing functionalities.

##Features

- Painting of prefabs with adjustable brush size
- Adjustable amount of prefabs per brush stroke
- Customizable rotation and scale
- Surface detection to adapt to uneven terrain
- Paint and erase modes
- Labeling of prefabs to manage selective deletion

##How to Use

1. **Assign Prefabs**:
   - Open the tool from `Tools > Prefab Painter`.
   - Assign up to 3 prefabs in the corresponding fields.

2. **Configure Brush**:
   - Adjust the brush size, number of prefabs per brush stroke, rotation and scale from the tool window.

3. **Paint**:
   - Select `Paint` mode and click on the scene to paint the assigned prefabs.

4. **Delete**:
   - Select `Erase` mode and click on the painted prefabs to erase them.

##Limitations

- This free version allows you to assign up to 3 prefabs. For more features, including the use of normal maps and other improvements, consider the Pro version.

Thank you for using Prefab Painter Tool!

# Prefab Painter Tool (Free Version)

## Overview

Prefab Painter Tool es una herramienta de Unity para pintar prefabs en tu escena de manera eficiente y natural. Esta versión gratuita permite asignar hasta 3 prefabs simultáneamente y ofrece funcionalidades básicas de pintado y borrado.

## Features

- Pintado de prefabs con tamaño de pincel ajustable
- Cantidad ajustable de prefabs por pincelada
- Rotación y escala personalizables
- Detección de superficie para adaptarse a terrenos irregulares
- Modos de pintado y borrado
- Etiquetado de prefabs para gestionar borrado selectivo

## How to Use

1. **Asignar Prefabs**:
   - Abre la herramienta desde `Tools > Prefab Painter`.
   - Asigna hasta 3 prefabs en los campos correspondientes.

2. **Configurar Pincel**:
   - Ajusta el tamaño del pincel, la cantidad de prefabs por pincelada, la rotación y la escala desde la ventana de la herramienta.

3. **Pintar**:
   - Selecciona el modo `Paint` y haz clic en la escena para pintar los prefabs asignados.

4. **Borrar**:
   - Selecciona el modo `Erase` y haz clic en los prefabs pintados para borrarlos.

## Limitations

- Esta versión gratuita permite asignar hasta 3 prefabs. Para más funcionalidades, incluyendo el uso de mapas de normales y otras mejoras, considera la versión Pro.

¡Gracias por usar Prefab Painter Tool!
